# TerminalRunner

TerminalRunner - небольшое приложение с текстовым интерфейсом для запуска заранее настроенных команд. Выберите команду из списка, следите за выводом и при необходимости остановите процесс.

## 🚩 Быстрый старт

Нужен Python 3.11 или новее.

### 🪟 Windows 

```powershell
py -m pip install .
terminalrunner
```

### 🐧 Linux 

```bash
python3 -m pip install .
terminalrunner
```

Приложение работает на Linux: запуск команд использует POSIX PTY, а цепочки команд запускаются через `/bin/sh`. Это проверяется в автоматических тестах на Ubuntu. Для Linux используйте Linux-пути и команды в своём `commands.yaml`.

## Как пользоваться 

1. Запустите `terminalrunner`.
2. Выберите команду стрелками или мышью.
3. Нажмите кнопку команды или `Ctrl+R` для запуска.
4. Наблюдайте за выводом в правой части окна.
5. Нажмите кнопку выполняемой команды или `Ctrl+X`, чтобы остановить её.

### ⌨️ Горячие клавиши 

| Клавиша | Действие |
| --- | --- |
| `Ctrl+R` | Запустить выбранную команду |
| `Ctrl+X` | Остановить текущую команду |
| `Ctrl+L` | Очистить вывод |
| `Ctrl+C` | Скопировать выделенный текст из вывода |
| `F1` | Показать полное описание выбранной команды |
| `F2` | Развернуть или свернуть панель команд |
| `Ctrl+Q` | Закрыть приложение |

История вывода ограничена 5 000 строками. Когда лимит достигнут, самые старые строки удаляются, чтобы приложение не расходовало память без ограничений.

## Свои команды

Заполните файл `commands.yaml` своими командами.

### 📖 Параметры команды

Каждая запись в `commands.yaml` может содержать следующие параметры:

| Параметр | Обязателен | Описание |
| --- | --- | --- |
| `title` | Да | Название, которое отображается в списке команд. |
| `description` | Нет | Пояснение к команде. Показывается в интерфейсе и полностью открывается по `F1`. По умолчанию пустая строка. |
| `executable` | Да, кроме разделителя | Команда вместе с аргументами, например `pytest tests -v`. Длинную команду можно перенести на несколько строк с `>-` YAML объединит их пробелами. Аргументы с пробелами заключайте в кавычки: `tool --message "Hello world"`. |
| `timeout_seconds` | Нет | Максимальное время выполнения в секундах. По умолчанию `3600` (1 час). Должно быть положительным целым числом. После истечения времени процесс останавливается. |
| `shell` | Нет | `true` запускает `executable` через командную оболочку: `cmd.exe` в Windows или `/bin/sh` в Linux. Нужен для `&&`, конвейеров и перенаправления. По умолчанию включается для команд с `&&`; в остальных случаях выключен. |

Пример команд со всеми параметрами:

```yaml
commands:
  # Записи только с `title` создают разделители в списке и не запускаются
  - title: Тесты

  - title: Запустить тесты
    description: Запускает тесты с подробным выводом не дольше 10 минут.
    executable: >-
      cd /home/user/service
      && pytest tests -v
    timeout_seconds: 600
    shell: true
```

## Сборка EXE для Windows

🛠️ В Windows выполните из корня репозитория:

```bat
build-exe.bat
```

Можно также дважды щёлкнуть `build-exe.bat` в Проводнике. Скрипт установит инструменты разработки, соберёт приложение через PyInstaller и создаст `dist\TerminalRunner.exe` вместе с `dist\commands.yaml`. Редактируйте `dist\commands.yaml`, чтобы изменить каталог команд без новой сборки.

## Подробнее для настройки и разработки

### 📄 Где ищется конфигурация

Конфигурация выбирается в этом порядке:

1. Путь из переменной окружения `TERMINALRUNNER_CONFIG`.
2. `commands.yaml` рядом с собранным EXE.
3. `commands.yaml` в текущей папке.
4. Встроенный каталог `terminalrunner/commands.yaml`.

Пример запуска с отдельным каталогом:

```powershell
$env:TERMINALRUNNER_CONFIG = "D:\Repos\TerminalRunner\commands.yaml"
terminalrunner
```

### 🔗 Цепочки команд

Для `&&`, конвейеров или перенаправления укажите `shell: true`:

```yaml
commands:
  - title: Собрать и запустить сервис
    executable: >-
      cd /home/user/service
      && ./build.sh
      && ./run.sh
    shell: true
```

На Windows такие команды запускаются через `cmd.exe`, на Linux - через `/bin/sh`. Используйте только доверенный `commands.yaml`: shell-команды имеют полный доступ от имени текущего пользователя. Для `.bat` и `.cmd` в середине Windows-цепочки используйте `call`.

Обычные команды запускаются без shell. Для Windows batch-файлов (`.bat`, `.cmd`) аргументы с метасимволами CMD (`&`, `|`, `<`, `>`, `(`, `)`, `^`, `%`, `!`, `"`) не поддерживаются.

### 💾 Состояние приложения

Выбранная тема и ширина панели команд сохраняются при выходе.

- Windows: `%LOCALAPPDATA%\TerminalRunner\state.json`
- Linux: `$XDG_STATE_HOME/terminalrunner/state.json` или `~/.local/state/terminalrunner/state.json`
- `TERMINALRUNNER_STATE` задаёт другой путь к файлу состояния.
